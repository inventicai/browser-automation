First-time setup

Self-hosted extension installs need Developer mode enabled once per browser. After that, updates roll in automatically.

  1. 1Open chrome://extensions in a new tab and flip Developer mode on (top-right).
  2. 2Click Download Brotto for Chrome above — Chrome saves brotto.crx to your Downloads folder.
  3. 3Drag the downloaded brotto.crx onto the extensions page, confirm the install prompt, and pin Brotto from the puzzle menu.
